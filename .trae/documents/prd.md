# 屋顶跑酷 - 产品需求文档 (PRD)

## 1. 产品概述
一款赛博朋克风格的屋顶跑酷游戏，玩家在黄昏城市建筑屋顶间跳跃奔跑，躲避障碍、收集信件碎片拼凑隐藏剧情。跑到一定距离后进入夜间关卡，视野缩小但霓虹更亮，营造沉浸式氛围变化。
- 目标用户：休闲游戏玩家、赛博朋克风格爱好者
- 核心价值：流畅跑酷手感 + 沉浸式视觉体验 + 剧情收集驱动力

## 2. 核心功能

### 2.1 用户角色
| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 玩家 | 昵称注册 | 游戏游玩、成绩查看、信件收集 |

### 2.2 功能模块
1. **游戏主界面**: 开始游戏、操作说明、排行榜入口、信件收集查看
2. **游戏画面**: Canvas跑酷主画面，包含角色、建筑、障碍、信件碎片
3. **结算界面**: 跑酷成绩、收集信件、重新开始/返回主页
4. **排行榜页面**: 按距离排名的全球成绩榜
5. **信件收集页面**: 已收集信件碎片及拼凑的剧情文本

### 2.3 页面详情
| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 游戏主界面 | 操作说明 | 展示空格跳跃、长按远跳、S滑铲的操作提示 |
| 游戏主界面 | 开始按钮 | 点击进入游戏，3-2-1倒计时后开始 |
| 游戏画面 | 角色控制 | 空格跳跃（长按跳更远，仅一段跳），S滑铲 |
| 游戏画面 | 障碍生成 | 随机生成晾衣绳（滑铲）、烟囱（跳跃）、天窗（避开） |
| 游戏画面 | 信件碎片 | 屋顶上随机出现信件碎片，碰触即收集 |
| 游戏画面 | 昼夜切换 | 距离达到阈值后渐变为夜间，视野缩小、霓虹更亮 |
| 游戏画面 | HUD显示 | 实时显示距离、已收集信件数 |
| 结算界面 | 成绩展示 | 显示本次距离、收集信件、最高纪录对比 |
| 排行榜 | 全球排名 | 按距离降序展示前20名玩家成绩 |
| 信件收集 | 碎片总览 | 展示所有信件碎片收集状态及拼凑的剧情文本 |

## 3. 核心流程

玩家进入主界面 → 点击开始 → 倒计时 → 角色自动向右奔跑 → 玩家操控跳跃/滑铲躲避障碍 → 收集信件碎片 → 距离增加触发昼夜切换 → 碰到障碍或掉落则游戏结束 → 结算界面展示成绩 → 成绩和信件进度保存到后端

## 4. 用户界面设计

### 4.1 设计风格
- **主色调**: 黄昏暖色调 — 橙红(#FF6B35)、琥珀(#FFA62F)、深紫(#2D1B69)
- **辅助色**: 霓虹粉(#FF1493)、霓虹蓝(#00FFFF)、霓虹绿(#39FF14)
- **按钮风格**: 圆角矩形，霓虹边框发光效果
- **字体**: Orbitron（标题/数字）+ Noto Sans SC（中文正文）
- **布局风格**: 全屏Canvas游戏区 + 覆盖层HUD
- **图标风格**: 像素风 + 霓虹描边

### 4.2 页面设计概览
| 页面名称 | 模块名称 | UI元素 |
|----------|----------|--------|
| 游戏主界面 | 标题区 | Orbitron大标题"SKYLINE RUNNER"，霓虹发光效果 |
| 游戏主界面 | 操作说明 | 半透明暗色卡片，按键图标+文字说明 |
| 游戏主界面 | 开始按钮 | 霓虹粉边框大按钮，hover发光增强 |
| 游戏画面 | 城市背景 | 多层视差滚动的建筑剪影，远处霓虹招牌闪烁 |
| 游戏画面 | 角色 | 赛博朋克风跑者剪影，跳跃/滑铲动画 |
| 游戏画面 | 障碍物 | 晾衣绳(横线+衣物)、烟囱(方块+烟雾)、天窗(半透明方块) |
| 游戏画面 | 信件碎片 | 发光信封图标，带粒子效果 |
| 游戏画面 | HUD | 左上距离计数器，右上信件收集计数 |
| 游戏画面 | 昼夜渐变 | 天空从暖橙渐变到深紫，建筑轮廓灯亮起 |
| 结算界面 | 成绩卡 | 半透明毛玻璃卡片，霓虹边框 |

### 4.3 响应式
- 桌面端优先设计，Canvas自适应窗口宽度
- 移动端：虚拟按键（跳跃按钮、滑铲按钮）覆盖在画面底部
- 最小支持分辨率 1024x600

### 4.4 游戏机制细节
- **跳跃**: 空格键触发，按住空格时间影响跳跃水平距离（0.1s-0.4s线性映射），垂直高度固定
- **滑铲**: S键触发，角色高度降低为1/3，持续0.6秒，期间无法跳跃
- **晾衣绳**: 位于角色头部高度，必须滑铲通过
- **烟囱**: 位于屋顶地面上，必须跳跃越过
- **天窗**: 位于屋顶地面上，踩上后0.3秒碎裂，角色坠落
- **角色**: 仅一段跳，无二段跳能力
- **信件碎片**: 共12封，每封3个碎片，集齐后解锁剧情文本
- **昼夜切换**: 距离达到1500m时渐变进入夜间，视野半径缩小40%，霓虹亮度增加200%
