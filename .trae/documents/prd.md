## 1. 产品概述

气球爆破大作战是一款解压休闲网页游戏，玩家通过点击从屏幕底部飘上来的气球来得分。游戏融合了风力系统、连击机制、多种气球类型和视觉特效，提供丰富的挑战性和爽快感。

- 目标用户：需要解压放松的休闲游戏玩家
- 核心价值：满屏气球飘浮的视觉治愈感 + 爆破得分的即时满足感 + 风力系统的策略挑战

## 2. 核心功能

### 2.1 功能模块

1. **游戏主界面**：全屏游戏区域、HUD信息显示、气球飘浮与交互
2. **准星选择面板**：展示已解锁和未解锁的准星样式，供玩家切换

### 2.2 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|---------|---------|---------|
| 游戏主界面 | 气球生成与飘浮 | 4种气球从底部随机生成并上浮，每帧3%概率生成 |
| 游戏主界面 | 气球点击爆破 | 点击气球触发爆破特效、音效、得分计算 |
| 游戏主界面 | 风力系统 | 每15秒风向变化，气球受风力水平漂移，顶部显示风向箭头 |
| 游戏主界面 | 连击系统 | 1秒内连续击破触发连击，倍率最高5倍，火焰数字显示 |
| 游戏主界面 | 生命系统 | 3条命初始，炸弹气球减命，0命游戏结束 |
| 游戏主界面 | HUD信息栏 | 分数、最高分、生命、风力指示、连击显示 |
| 游戏主界面 | 准星系统 | 鼠标替换为准星图标，击破时冲击波特效，可解锁多种样式 |
| 游戏主界面 | 存档系统 | localStorage保存最高分和已解锁准星样式 |

## 3. 核心流程

玩家打开游戏后，气球从屏幕底部不断飘上来，玩家移动准星点击爆破气球得分。红色和蓝色气球是普通得分目标，金色气球提供高分奖励，炸弹气球需要避开。风力系统每15秒变化一次，影响气球水平漂移方向，增加击破难度。1秒内连续击破多个气球触发连击，连击倍率提升得分。生命耗尽时游戏结束，历史最高分自动保存。

## 4. 用户界面设计

### 4.1 设计风格

- 主色调：深蓝夜空渐变背景（#0a0a2e → #1a1a4e），营造梦幻夜空氛围
- 强调色：金色（#FFD700）用于高分提示，红色（#FF4444）用于警告
- 气球颜色：鲜红（#FF3B3B）、天蓝（#3B8BFF）、金色（#FFD700）、黑色（#1a1a1a）
- 字体：数字使用粗壮的 Impact 风格，UI文字使用圆润风格
- 布局：全屏Canvas游戏区域，HUD叠加在画面上方
- 特效风格：粒子飞散、光晕脉冲、火焰环绕，营造炫酷爆破感

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI元素 |
|---------|---------|--------|
| 游戏主界面 | 背景 | 深蓝渐变夜空，远处微小星星闪烁 |
| 游戏主界面 | HUD顶栏 | 左侧分数+最高分，中间风力指示器（箭头+数值），右侧生命心形 |
| 游戏主界面 | 连击显示 | 右上角火焰数字，随连击数放大，周围火焰粒子环绕 |
| 游戏主界面 | 气球 | CSS圆形+高光反射+细线绳，金色有光晕脉冲，炸弹有红色闪烁边框 |
| 游戏主界面 | 准星 | 十字/圆环/鹰眼/激光四种样式，击破时冲击波圆环扩散 |
| 游戏主界面 | 游戏结束 | 半透明遮罩+居中结果面板，显示得分+最高分+重新开始按钮 |

### 4.3 响应式设计

- 桌面优先设计，Canvas自适应全屏
- 触屏设备支持触摸点击爆破
- 窗口缩放时自动调整Canvas尺寸
