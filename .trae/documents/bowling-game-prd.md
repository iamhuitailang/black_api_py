## 1. 产品概述

街机保龄球是一款纯前端的 2D 保龄球游戏，模拟真实保龄球体验。玩家通过三步点击操作（定位→力度→旋转）完成投球，体验不同球道条件下的物理效果，解锁多种特殊球，追求 300 分满分。

- 目标用户：休闲游戏玩家、保龄球爱好者
- 核心价值：街机式操作手感 + 策略性球道/球选择 + 持久化进度

## 2. 核心功能

### 2.1 功能模块

1. **游戏主界面**：球道画面、计分板、球选择、球道条件选择
2. **投球控制系统**：位置选择器、力度条、旋转条三步操作
3. **球道物理引擎**：球瓶碰撞、连锁击倒、弧线轨迹
4. **球道条件系统**：干道/标准道/油道三种条件
5. **球解锁系统**：5 款可解锁球，不同属性加成
6. **计分系统**：标准保龄球 10 帧计分规则，含 Strike/Spare 奖励
7. **音效系统**：全中欢呼、补中鼓励、失误叹息
8. **存档系统**：localStorage 持久化游戏进度

|---------|---------|---------|
| 游戏主界面 | 球道 Canvas | 渲染球道、球、球瓶，动画物理模拟 |
| 游戏主界面 | 投球控制条 | 位置指示器/力度条/旋转条，三步点击操作 |
| 游戏主界面 | 计分板 | 标准 10 帧保龄球计分显示，实时更新 |

## 3. 核心流程

### 3.1 投球流程

1. 玩家左右移动鼠标控制投球位置，点击锁定位置
2. 力度条自动上下摆动（速率 2px/frame），点击锁定力度
3. 旋转条自动左右摆动，第三次点击确定旋转量
4. 球按锁定参数投出，受旋转影响产生弧线轨迹
5. 球碰撞球瓶，触发直接击倒和连锁击倒判定
6. 计算得分，更新计分板

## 4. 用户界面设计

### 4.1 设计风格

- **主色调**：深木色球道（#2C1810）+ 白色球瓶 + 彩色球
- **辅助色**：霓虹橙（#FF6B35）作为强调色，复古街机感
- **背景**：深色渐变背景，模拟保龄球馆氛围
- **字体**：像素风/街机风显示字体，搭配简洁 UI 字体
- **按钮风格**：圆角矩形，霓虹发光边框，街机投币感
- **布局**：左侧球道 Canvas 主画面，右侧控制面板+计分板

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI 元素 |
|---------|---------|---------|
| 游戏主界面 | 球道 Canvas | 深色木纹球道、白色圆形球瓶、彩色球、球沟标识 |
| 游戏主界面 | 投球控制 | 垂直力度条（红绿渐变）、水平旋转条（左右摆动指针）、位置指示箭头 |
| 游戏主界面 | 计分板 | 10 帧格子，Strike 显示 X，Spare 显示 /，数字居中 |
| 游戏主界面 | 球选择 | 5 个球圆形缩略图，选中高亮，未解锁灰色+锁图标 |
| 游戏主界面 | 球道条件 | 三个按钮，选中态带发光边框 |

### 4.3 响应式设计

- 桌面优先，Canvas 固定尺寸 400×700
- 控制面板在右侧垂直排列
- 最小支持 1024px 宽度

## 5. 物理参数规格

| 参数 | 值 | 说明 |
|-----|---|------|
| 球半径 | 15px | 球的碰撞半径 |
| 球瓶半径 | 6px | 球瓶碰撞半径 |
| 球瓶行间距 | 25px | 三角形排列纵向间距 |
| 球瓶列间距 | 15px | 三角形排列横向间距（约） |
| 击出速度系数 | 0.6 | 被击球瓶速度 = 球速 × 0.6 |
| 连锁判定半径 | 12px | 飞出瓶击倒相邻瓶的判定距离 |
| 旋转偏移系数 | 0.3px/frame | 偏移量 = 旋转值 × 0.3 |
| 力度条速率 | 2px/frame | 力度条上下摆动速度 |
| 干道旋转倍率 | ×1.5 | 干道旋转效果增强 |
| 油道旋转倍率 | ×0.3 | 油道旋转效果减弱 |
