❓ 操作说明

🎮 基础操作

  • ← → 或 A D：左右切换车道
  • 空格 或 W：跳跃（越过路障）
  • S：蹲低/蹬地（上坡时加速）
  • Q：向左倾斜（过左弯道）
  • E：向右倾斜（过右弯道）

🎯 技巧动作（精准按键！）

  • 跳跃中按 F：空翻（成功+100，失败-50）
  • 跳跃中按 G：抓板（成功+60）
  • 接近栏杆时按 R：滑轨（持续1秒+80）

🛣️ 地形说明

  • 平路：基础速度 40
  • 下坡：加速到 70
  • 上坡：减速到 25，按住 S 蹬地加速
  • 弯道：需提前倾斜，否则摔出损失3秒

🚧 障碍物

  • 路障（锥形桶）：跳跃越过
  • 行人：左右躲避
  • 其他滑板者：超越获得 50 积分
